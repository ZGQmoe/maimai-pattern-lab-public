# Mailab

正式名称 **Mailab**。曾用名 Maikiri 及其命名来历保留在历史记录中。

开发前必读：[需求基准](REQUIREMENTS.md) → [项目分工](PROJECT.md)。首次接手见 [Claude × Codex 交接与下一项开发任务](HANDOFF.md)。历史想法见 [公开摘要](IDEAS-RECORD.md)。当前沿用 maimai 圆屏界面，重点完善谱面兼容性和规则识别。机器学习识别留待后续。

maimai DX 局部配置检索原型。目标是按配置、整谱等级和局部强度发现跨曲目片段，包括不热门的曲目，并提供定位预览。已有结果列表、定位 Preview 与可解释局部条件；广泛谱库与更多配置识别器仍未完成，当前能力以下文为准。静态响应式网页，谱面在浏览器解析，不需要 API key、账号或服务器数据库。

## 运行和验证

Node 22+：`node --test test.mjs`；本机批量扫描 `node tools/scan.mjs <目录或 .adx>`。任意静态服务器指向 `dist/`（例如 `python3 -m http.server 8080 -d dist`）。部署可使用 Sites、GitHub Pages、Cloudflare Pages 或其他静态托管。

## AstroDX 谱面输入与识别

- [AstroDX 的 ADX 指南](https://wiki.astrodx.com/cn/install/android)说明 `.adx` 使用 ZIP 容器。可以从 [ADX 谱面资源](https://adxdls.saop.cc/) 查找包，或把有权使用的 Simai 谱面文件放进曲目目录再打包。该目录的站点代码、目录数据和实际谱面分别授权，详见[来源说明](https://github.com/AdingApkgg/adx-dl#许可与署名)。
- 导入在浏览器内完成，仅读取包中的 `maidata.txt`，跳过音源、封面、视频和合集清单。每包上限 100 MB、100 份谱面文本、100 张难度谱。常见 ZIP 压缩使用本地 vendored [zip.js 2.24.0](https://github.com/gildas-lormeau/zip.js/releases/tag/v2.24.0)，随附 BSD-3-Clause 许可。压缩包读取和 Simai 语法解析分开报告。
- `&title`、`&lv_n` 和 `&inote_n` 区分曲目、标注等级和难度谱。等级只作筛选。目标等级按钮和导入单谱选项均覆盖 12、12+、13、13+、14、14+、15。「12 及以上」可浏览高于该范围起点的导入谱面，不推断小数定数与显示等级的映射。
- `&first`、BPM、细分和时间格把每个 Note 映射到拍位与时间。Tap 键位序列可找同键重复或两键交替，同时押应按同一时间格处理。用旋转、镜像和相对节奏对齐比较结构，另算以秒为单位的速度和密度。
- Slide 起点、终点、路径符号、等待与时值可构造活动区间。若区间内穿插 Tap，可形成 Slide–Tap 交织候选。重叠的 Slide 区间可形成多重 Slide 候选。这两个方向仍需用样本确定规则边界，文件也不提供真实手法或玩家成绩。[Simai Slide 规范](https://w.atwiki.jp/simai/pages/23.html)
- 用 [chika3742 的 Synthesis. 自制谱](https://github.com/chika3742/majdata-charts/tree/main/synthesis)复核了曲名、等级和谱面字段。此前基础解析在第一格的链式 Slide 报错；2026-11-07 已支持链式与同头 Slide，但本会话无法访问该仓库，未重新扫描验证。ADX 封包兼容与谱面语法兼容分别验收。

## 已实现

- maidata 多 inote、lv、title、first 字段或受限单谱 Simai；支持筛选 12/12+/13/13+/14/14+/15，原创样例覆盖 12–15 各等级，等级只用于演示。
- BPM、细分、Tap/Break/EX、Hold/Touch、单段基础 Slide，Note 时间与位置。纯 Tap 同时押支持 `12`、`123` 等省略斜线的简写，空白 `inote_n` 难度字段会被跳过。
- 专项检索支持连续单 Tap 纵连、两位置交互及旋转/镜像规范化。普通单点、基础 Slide 不在专项选项或全部专项结果中。
- [社区经典配置清单](PATTERNS.md)收录 23 个候选，页面可分组选择、查阅教程。只有纵连和交互已有基础规则，其余均明确标为待研究。
- 不需参考片段：选配置和整谱等级即列出跨曲目命中片段。每条含曲名、难度谱、整谱等级、配置与交互跨度、起止时间、约第几小节、命中依据和局部特征（音符数、平均速率、最短间隔、细分、等/不等间隔、BPM、片段内其他 Note）。同一曲目多段分别列出，可按曲名/速率/间隔/音符数/模型负荷排序，超过 30 条分页。
- 局部条件（可选）：平均速率上下限、音符数下限、等/不等间隔、交互跨度（相邻/隔一键/隔两键/对侧）。只按片段自身音符计算，不是实测难度；被条件排除的段数单独显示。
- Preview：点结果在 Canvas 圆屏中从目标前约 2 秒开始播放（减少动态效果时停在目标起点），可暂停、拖动、±0.05 秒步进、0.25×/0.5×/1× 速度，键盘空格/方向键可用。时间轴标出目标范围；播放范围单独计算，自动补入跨越边界的 Hold、Slide 与星星头并标紫色。无音频；弧形/折线类 Slide 轨迹为近似绘制。
- 扫描覆盖：练习库面板列出扫描、成功解析、失败数，按整谱等级统计纵连/交互命中，失败原因分类列出；空结果按“识别器未支持 / 没有该等级谱面 / 被局部条件排除 / 解析失败而未知”分别说明。命令行 `node tools/scan.mjs <目录或 .adx>... [--family 交互 --level 13+] [--json]` 在本机批量扫描同样的数据，不上传。
- 可选“找相似”：选参考片段后按局部负荷策略筛选（0.9 / 1.1 倍阈值为工程占位）。
- 解释密度、持续、干扰、前后上下文；练习库 JSON 导入导出；不上传谱面。

## Preview 渲染方案的取舍

评估了 [adx-dl 的 maimai-chart-engine](https://github.com/AdingApkgg/adx-dl/blob/main/packages/maimai-chart-engine/README.md)：代码为 MIT（vendored 自 Lxns-Network/maimai-prober-frontend），Canvas 2D，自带 simai 解析器。暂不采用：它以 TypeScript 源码形式提供（`exports` 指向 `src/index.ts`），需要打包步骤；与 Mailab 解析器是两套输入，命中片段的时间与 Note 对应需另行核对；README 未记录 seek / 时间窗口 API。当前改用 `dist/preview.js`，直接绘制 Mailab 解析出的 Note，确保预览与命中依据同源。若以后需要更精确的 Slide 轨迹，再评估接入并做兼容性测试。

## 明确限制

解析器为受限自实现，未宣称完整兼容 Simai。研究了 MIT 的 simai-sharp-ts（https://github.com/Shikochin/simai-sharp-ts），当前未复制或依赖其代码。lcebot/maidata-parser 是专有许可，未采用。后续以真实合法测试集评估再接入成熟解析器。

已支持：链式 Slide（末段总时值或每段时值）、`*` 同头多 Slide、`V` 折线、`pp`/`qq`、`[bpm#a:b]`、`[bpm#秒]`、`[等待##秒]`/`[等待##a:b]`、Touch Hold、`$ @ ? !` 星星修饰（`? !` 记为无星星头）。仍不支持：伪 EACH（`）、`<HS*…>` 等变速标记、`{#秒}` 绝对步长、链中只有部分段写时值；遇到未知 token 拒绝整谱。基础 Slide 仅保存几何类型、起终点、等待和持续，不做判定轨迹。没有完整手法推断，旋转镜像对 Slide 只作模式近似；尤其顶部/底部曲线规则不能当作精确几何等价证明。

纵连与交互仅识别连续单 Tap。同时押会打断识别，含同时押的变体可能漏检。负荷无玩家实测校准，不能输出水歌/诈称结论。结构相似度为规范化 token 匹配，非学习模型；速度独立于身份，但时值比例的细微差别会量化。推荐仅针对当前导入库，不包含商业谱库和音源，不保证整曲可打。

扫描上限 500KB/文件、15000 Note/谱；上下文扫描为 O(片段×Note)。请先使用小规模库，性能达到瓶颈再做区间索引。

## 版权与隐私

附带样例是本项目原创合成练习，无商业曲目数据。仅导入你有权使用的谱面。默认不联网传输谱面；导出文件包含导入原文，请自行保管。改名沿用原浏览器数据库，既有谱面不需重新导入。导出文件使用 mailab-library.json。静态网站跨设备可访问；练习库在当前浏览器自动保存，可通过导出/导入跨设备转移。清除浏览器网站数据会删除本机练习库，请保留导出备份。
